# Huntober - CAR + EUE + PREP

**C**ause -- **A**ction -- **R**esult

C - Plain, open ended language. Don't snitch on yourself!
A - Positive. Show competence and initiative!
R - Quantify the improvement. Show everything is directionally better!

**E**xplanation -- **U**se -- **E**xample

E - Explain what it is, give real world use case.
U - Citing real examples signals industry familiarity
E - Something relatable

**P**arameters -- **R**eturns -- **E**xamples -- **P**seudocode

PREP should be used as a framework for coding challenges.
